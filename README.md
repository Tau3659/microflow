# 菌流 · MICROFLOW

手机浏览器可玩的微观进化吞噬游戏。

## 操作

- **左侧虚拟摇杆**：控制游动方向
- **右侧加速键**：短暂冲刺（有冷却）
- 桌面可用 WASD / 方向键 + 空格加速

## 玩法

1. 接触 **蛋白质** 增加点数  
2. 点数足够后，吞食发光的 **DNA** 进化  
3. 进化后开启通道，可前往 **上一层生物圈**  
4. 吞噬敌方 **细胞核** 可消灭对方；自己的核被吃掉则结束  
5. 普通生物与 Boss 被消灭后会 **分解**，掉落蛋白质和 DNA  
6. 每层有一只多细胞核的攻击性 Boss  

## 进化路线

原核细胞 → 真核单细胞 → 原始多细胞 → 复杂多细胞 → 病毒聚合体

## 本地运行

```bash
npm start
```

浏览器打开 `http://localhost:4173`。

## 生物外观图鉴

逐一预览 / 调整全部生物外观，再同步回游戏代码：

```bash
npm start
```

打开 `http://localhost:4173/tools/gallery.html`

1. 左侧选择生物，右侧调参（自动保存在浏览器本地）
2. 点 **导出 JSON**，保存为 `tools/creature-looks.json`
3. 执行同步：

```bash
npm run sync:looks
```
