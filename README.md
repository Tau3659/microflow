# 菌流 · MICROFLOW

手机浏览器可玩的微观进化吞噬游戏。

## 操作

- **移动**：左侧虚拟摇杆只改方向，推得越满越快（不耗槽）
- **加速**：右侧技能键按住释放；桌面空格同一套。按下不改瞄准
- 桌面可用 WASD / 方向键调试方向

## 玩法

1. 接触 **蛋白质** 增加点数  
2. 点数足够后，吞食发光的 **DNA** 进化  
3. 进化后开启通道，可前往 **上一层生物圈**  
4. 吞噬敌方 **细胞核** 可消灭对方；自己的核被吃掉则结束  
5. 普通生物与 Boss 被消灭后会 **分解**，掉落蛋白质和 DNA  
6. 每层有一只多细胞核的攻击性 Boss  

## 进化路线

原核细胞 → 真核单细胞 → 原始多细胞 → 复杂多细胞 → 病毒聚合体

## 本地运行

```bash
npm run serve
```

浏览器打开 `http://localhost:4173`。

## Three.js 重制版

本仓库同时包含一个使用 Three.js / WebGL 渲染的重制版，核心玩法、进化节奏与操作手感与原版保持一致。

```bash
npm run serve
```

- 原版 Canvas 版：`http://localhost:4173/`
- Three.js 重制版：`http://localhost:4173/three/`

两个版本首页互相保留入口链接，原版仍可正常游玩。

### 运行/播放方式

1. 启动任意静态服务器（仓库根目录 `npm run serve` 已提供）。
2. 用浏览器打开 `http://localhost:4173/three/`。
3. 点击播放按钮开始；移动端使用左侧虚拟摇杆移动、右侧按钮加速，桌面端可用 WASD / 方向键 + 空格。
4. 点击右上角 × 返回标题。

### 保留与差异

- **保留**：完整的核心循环（移动、吞噬蛋白质 / DNA、进化、层级传送、Boss 与 NPC 行为、吃核死亡、音效与 HUD）。
- **渲染差异**：从 Canvas 2D 改为 Three.js WebGL，生物体、细胞核、鞭毛、刺突、蛋白质等使用 3D 几何体（球体、胶囊、圆锥、精灵）组合呈现，同时保持俯视微观的视觉感受。
- **新增/调整**：
  - 背景层使用 WebGL shader 渐变，深海尘埃与视差光斑改为 Three.js 精灵。
  - 相机仍为俯视 OrthographicCamera，视野大小与原版一致。
  - 未修改游戏规则、数值、进度与交互逻辑；`three/js/` 中除渲染器与入口外，其余模块直接来自原版。
