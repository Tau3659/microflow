# 菌流 · MICROFLOW

一款可在手机浏览器运行的 flOw 风格微观吞噬游戏。

## 玩法

- 按住屏幕（或按住鼠标）引导你的生命体游动
- 吞食光点与更小的生物以成长
- 避开明显更大的捕食者；被擦伤会缩小，被远超体型的生命吞没则结束
- 质量足够后，游入「下潜」漩涡，进入更深层级
- 共有四层：表层 → 中层 → 深渊 → 渊底

## 本地运行

任意静态服务器即可，例如：

```bash
npm run serve
# 或
npm start
```

然后用手机或桌面浏览器打开 `http://localhost:4173`。

手机访问时，请保证与电脑同一局域网，并用电脑的局域网 IP 访问。

## 技术

- 纯前端：HTML / CSS / Canvas / ES Modules
- 无需构建步骤，适配触控与安全区
- 主要逻辑在 `js/` 目录
